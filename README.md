# Effect Lens Monorepo

A Lens type for [Effect](https://effect.website/) to easily manage nested state.

This monorepo contains:
- [The `effect-lens` library (for Effect v4)](packages/effect-lens)
- [The `effect-lens` library (for Effect v3, legacy)](packages/effect-lens-legacy)

Both lines are published as `effect-lens`: v4 under `latest`, the legacy v3 line under `legacy`.
